# Severity Levels

| Level | Meaning | Example | Response |
|---|---|---|---|
| Low | Minor issue, no data affected | A blocked phishing email nobody opened | Review within 3 working days |
| Medium | Limited impact on one user or system | A user clicked a suspicious link but entered nothing | Review within 1 working day |
| High | Possible loss of data or account access | A user entered their password on a fake login page | Respond within a few hours |
| Critical | Serious damage or many users affected | Malware spreading across the network | Respond immediately |

When unsure, choose the higher level. It can always be lowered after review.
