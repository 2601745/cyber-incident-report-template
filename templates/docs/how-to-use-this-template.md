# How to Use This Template

1. **Copy** `templates/incident-report-template.md` and give the copy a clear name, for example `2026-11-04-phishing-email.md`.
2. **Fill in** every field you can. If you do not know something, write "unknown" rather than guessing.
3. **Describe the facts**: what you saw, what you clicked or entered, and when.
4. **Choose a severity level** using `docs/severity-levels.md`.
5. **Submit** the report to the security team straight away. Do not wait until you have all the details.
6. **Do not include** real passwords or other secrets in the report.
