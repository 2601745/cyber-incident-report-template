# Cybersecurity Incident Report Template

A simple template and short guides to help staff report cybersecurity incidents clearly and quickly.

## Contents
- `templates/incident-report-template.md`: the blank report form
- `docs/how-to-use-this-template.md`: step-by-step instructions
- `docs/severity-levels.md`: how to rate how serious an incident is
- `examples/sample-completed-report.md`: a fictional filled-in example

## Why it matters
A clear, fast and complete report helps the security team contain an incident sooner and learn from it afterwards.

## Who is it for?
Any staff member, student or junior analyst who needs to report a suspected incident such as phishing, malware or unauthorised access.

## Note
This repository contains no real incident data, names or credentials. The example report is fictional.
